# Primo AI Demo

Interactive process discovery and improvement demo for Primus Software Corporation.

## Local development

```bash
npm install
npm run dev
```

## Netlify

- Build command: `npm run build`
- Publish directory: `dist`

The demo separates Product Owner Intake from Process SME Discovery and includes a dashboard, repository, process workspace, BPMN editor, diagnosis, improvements, readiness, reports, and a simulated PrimeOne handoff.
